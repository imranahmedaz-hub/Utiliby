Security & Privacy Tools

Free online tools to test passwords, create hashes and keys, encrypt text and files, and check your browser privacy. Everything runs in your browser — no sign-up, no tracking.

Password Strength CheckerTest a password, see how long it would take to crack and why. Hash GeneratorMD5, SHA-1, SHA-256, SHA-512 and CRC32 of text or files, with HMAC and compare. Text Encryption ToolEncrypt and decrypt messages with AES-256 and a password. 2FA Code GeneratorTime-based 2FA codes from a secret, with a checker and QR setup code. Breached Password CheckerSee if a password appeared in a data breach, sending only 5 hash characters. File Encryption ToolEncrypt and decrypt any file with AES-256 and a password in your browser. Passphrase GeneratorStrong, memorable random-word passphrases with exact strength in bits. Browser Fingerprint CheckerSee what websites can read about your browser and device without cookies. API Key GeneratorRandom API keys, secrets, tokens and UUIDs with exact strength in bits. My IP Address CheckerSee your public IP address and test for VPN and WebRTC leaks.
