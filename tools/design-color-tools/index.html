Design & Color Tools

Free online tools for picking, mixing and converting colours, building palettes and gradients, and designing CSS effects such as frosted glass. Everything runs in your browser, with no sign-up and no tracking.

Color PickerPick any colour and get HEX, RGB, HSL, HSV, CMYK, Lab and OKLCH codes with an eyedropper and harmonies. Color Palette GeneratorGenerate colour palettes in 12 modes, lock favourites and export CSS, SCSS, Tailwind, JSON, SVG and PNG. Image Color PickerPick colours from any photo or screenshot and extract a dominant colour palette with HEX codes. CSS Gradient GeneratorBuild linear, radial and conic CSS gradients with up to 10 stops, then copy CSS, Tailwind, SVG or PNG. HEX to RGB ConverterConvert HEX, RGB, HSL, HSV, CMYK, Lab and OKLCH both ways, in bulk, with code snippets for 20 tools. Color WheelFind complementary, triadic and analogous colours on an RGB or RYB colour wheel and export the scheme. Color MixerMix two to six colours, compare six mixing methods and find a paint recipe for any target colour. Tints and Shades GeneratorMake lighter and darker versions of any colour and build a 50 to 950 scale for CSS, SCSS or Tailwind. Glassmorphism GeneratorDesign frosted glass cards and navbars with live blur and transparency, then copy CSS, Tailwind or React. Color Name IdentifierName any colour: find the closest CSS colour name for a HEX, RGB or picked colour.
