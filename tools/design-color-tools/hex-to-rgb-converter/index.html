How HEX colour codes work

A HEX code is written in base 16 (hexadecimal), which uses the digits 0 to 9 and the letters A to F, where A is 10 and F is 15. Two hex digits can show 256 values, from 00 (0) to FF (255), exactly the range of one colour channel. A six-digit code is therefore the red pair, the green pair and the blue pair in a row.

Manual method: multiply the first digit of the pair by 16 and add the second. For #0369A1: 03 gives 0×16+3 = 3, 69 gives 6×16+9 = 105 and A1 gives 10×16+1 = 161. To go back, divide by 16: 255 gives 15 remainder 15, which is FF; 99 gives 6 remainder 3, which is 63; and 71 gives 4 remainder 7, which is 47, so rgb(255, 99, 71) is #FF6347.

RGB, HSL, HSV, HWB and CMYK compared

RGB mixes red, green and blue light and is how screens work. HSL describes the same colour as a hue angle, a saturation and a lightness, which suits tweaking and theming. HSV or HSB swaps lightness for brightness and is common in design-app colour pickers. HWB describes hue plus how much white and black to add, a simple model that is now part of CSS. CMYK mixes cyan, magenta, yellow and black ink for print.

Lab, LCH, OKLab and OKLCH: perceptual colour

RGB numbers are not evenly spaced for human vision: adding 20 to the blue channel looks different from adding 20 to green. CIE Lab and LCH were designed to fix that, with a lightness axis and colour axes that follow how people see. OKLab and OKLCH improve on them, and are now supported in CSS with the oklch() function. They make it easy to build palettes with even steps, adjust lightness without changing hue and blend gradients smoothly. This converter shows all four, using the D50 white point for Lab and LCH as CSS does.

If you type a very vivid value that an ordinary screen cannot show, the tool adjusts it to the nearest sRGB colour and tells you. To explore these values visually, use the Color Picker or build gradients in OKLab with the CSS Gradient Generator.

Checking and troubleshooting conversions

  • Off by one. Rounding is the usual cause. Convert from the original format when you can.
  • CMYK looks different in print. The tool does a simple conversion. Printers use profiles and inks.
  • HEX has the wrong length. Use 3, 4, 6 or 8 digits. Five or seven digits are not valid.
  • Lowercase or uppercase. Both mean the same. Use lowercase for CSS if your style guide says so.
  • Alpha in the wrong place. CSS uses #RRGGBBAA, Android uses #AARRGGBB.
  • Colour changes in an app. Check the colour profile. Display P3 images can look more vivid than sRGB.

Accuracy, limits and responsible use

All conversions use published formulas and run in your browser. Values are rounded for display, so converting through several formats can drift by one step. The tool assumes sRGB, which is what the web uses by default. It does not manage colour profiles and CMYK is not profile-based, so use professional colour management for print, packaging and brand-critical work. Frequently asked questions

How do I convert HEX to RGB?

Split the HEX code into three pairs and convert each pair from base 16 to decimal. For #0369A1, 03 is 3, 69 is 105 and A1 is 161, so the RGB value is rgb(3, 105, 161). The tool does this instantly when you paste the code.

How do I convert RGB to HEX?

Convert each of the red, green and blue numbers to a two-digit base-16 value and join them. For rgb(255, 99, 71), 255 is FF, 99 is 63 and 71 is 47, giving #FF6347. Type the numbers into the RGB fields to see it.

What is a HEX colour code?

A HEX colour code is a six-digit base-16 number, written after a hash sign, that gives the amount of red, green and blue in a screen colour. #000000 is black and #FFFFFF is white.

What is the difference between HEX and RGB?

They describe the same colours. HEX writes the three channel values in base 16 as one code, while RGB writes them as three decimal numbers from 0 to 255.

What does a 3-digit HEX code mean?

It is shorthand where each digit is doubled. #F60 means #FF6600. Only colours whose pairs have matching digits can be shortened.

What is an 8-digit HEX code?

The last two digits are opacity. #0369A180 is the colour #0369A1 at about 50 percent opacity, because 80 in base 16 is 128 out of 255.

How do I convert HEX to HSL?

Paste the HEX code and read the HSL fields. The tool converts to hue in degrees, then saturation and lightness in percent, for example #0369A1 becomes hsl(201, 96%, 32%).

How do I convert HEX to CMYK?

Paste the HEX code and read the CMYK fields. The result is a simple mathematical conversion. Printers use colour profiles, so the printed colour can differ.

Can I convert many colours at once?

Yes. Open the Bulk converter tab, paste one colour per line in any format and choose an output format. You can copy the results or download them as a CSV file.

Which colour formats can I paste?

HEX with 3, 4, 6 or 8 digits, rgb(), rgba(), hsl(), hsla(), hsv(), hwb(), cmyk(), lab(), lch(), oklab(), oklch(), CSS colour names, and plain numbers such as 255, 99, 71.

What is OKLCH and why convert to it?

OKLCH is a modern CSS colour format that describes lightness, chroma and hue in a way that matches human vision. It is useful for building palettes where equal steps look equal.

What is a web-safe colour?

A web-safe colour is one whose red, green and blue values are each 0, 51, 102, 153, 204 or 255. They were useful on 256-colour displays and are rarely needed today.

How do I convert a colour to a decimal number?

Multiply red by 65536, green by 256 and add blue. The tool shows this in the Decimal field. For example #0369A1 is 223649.

How do I use the colour in Swift, Android or Flutter?

Open the Code snippets tab. It lists ready-to-paste code for UIColor, SwiftUI, Android XML, Kotlin, Java, Flutter, Unity, C#, Python, R and more.

Why is my converted value off by one?

Colour values are rounded to whole numbers for display. Converting through HSL or CMYK and back can differ by one step in a channel because of rounding.

Does it work with transparent colours?

Yes. Use the opacity field or an 8-digit HEX or rgba() value. The tool shows rgba(), hsla() and 8-digit HEX results.
