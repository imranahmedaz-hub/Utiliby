What is a free color name identifier online?

A free color name identifier online takes a colour value (a HEX code, an RGB triplet, an HSL value or a pixel from an image) and shows the closest matching colour name from a list of named colours. Instead of seeing #DC143C and wondering whether it is red, pink or crimson, you get a name you can say out loud: Crimson.

This colour name finder compares your colour with a list of more than 1,000 named colours, using the CIEDE2000 perceptual distance formula so that the closest match is the one that looks closest to the eye. It shows the nearest name, four similar names, the colour in HEX, RGB, HSL, CMYK and LAB, four colour harmonies, a WCAG contrast check and a simplified colour vision deficiency simulation. Everything runs in your browser, and your colours and images are not uploaded.

A colour name is a description and not an official specification. The name shown is the nearest match in this tool's list, so use the colour codes whenever you need an exact value.

How to find the name of a color from a HEX code

  1. Open the Hex tab and type or paste your code, for example #4F46E5.
  2. Read the name beside the swatch. For that code the tool shows Majorelle Blue with a distance of 3.3, which means a close but not exact match.
  3. Look at the similar colours below the name if you want a more specific or more familiar name.
  4. Scroll down to copy the colour in other formats, check contrast or open the harmonies.

For a colour that is exactly in the list, the distance is 0. For example, #DC143C is Crimson with distance 0.0, and #FF7F50 is Coral with distance 0.0.

How colour name identification works

Every colour can be described as a point in three-dimensional space. In RGB space, equal distances do not look equally different to the eye, so a plain RGB comparison can pick a name that does not look like the closest one.

To match colours the way people see them, the tool converts your colour into CIELAB and measures the CIEDE2000 distance to each name in the list. CIEDE2000 is a widely used formula for perceptual colour difference that weights lightness, chroma and hue differences according to how sensitive the eye is to each. The smallest distance wins, and the next four become the similar colours.

The distance is shown under the name. Zero means an exact match, and a lower number means a closer one. As a rough rule of thumb, a distance of about 1 is hard to notice, while larger numbers describe a more visible difference. It is a guide and not a certification.

Colour formats explained

Every colour can be expressed in several formats, and the tool shows them all for the selected colour.

HEX

A # followed by six hexadecimal characters, one pair each for red, green and blue. #FF0000 is pure red. HEX is the usual format for web design and CSS.

RGB

Three integers from 0 to 255, one per channel, such as rgb(220, 20, 60). RGB is how screens mix light.

HSL

Hue (0 to 360 degrees), saturation and lightness as percentages, such as hsl(348, 83%, 47%). HSL is easier to reason about when you want a lighter, darker or less saturated version.

CMYK

Cyan, magenta, yellow and black percentages for print. The conversion from RGB is approximate because inks and screen light behave differently, so treat it as a starting point and check a printed proof.

LAB

A colour space built around perceived lightness (L) and two colour axes (a and b). The tool uses it internally to compare colours.

What are colour harmonies?

Colour harmonies are combinations that sit in particular positions on the colour wheel, and many designers find them balanced. The tool generates four from your colour:

  • Complementary: two colours opposite each other, 180 degrees apart. High contrast, good for accents.
  • Analogous: three neighbouring colours within about 30 degrees. Calm and cohesive.
  • Triadic: three colours spaced 120 degrees apart. Lively and balanced.
  • Split-complementary: a base colour plus the two colours beside its complement. Strong contrast with less tension.

For a full wheel and more schemes, try the Color Wheel.

WCAG contrast and accessibility

The Web Content Accessibility Guidelines (WCAG) set minimum contrast ratios between text and its background. At level AA, normal text needs at least 4.5:1 and large text needs at least 3:1. At level AAA the figures are 7:1 and 4.5:1. The tool shows the ratio of your colour against white and black with the matching rating, so you can see at a glance which one reads better on it. For testing a specific text and background pair, use the Color Contrast Checker.

Colour vision deficiency simulation

Roughly 1 in 12 men and 1 in 200 women have some form of colour vision deficiency, with figures varying by population. The tool shows a simplified approximation of how your colour might look with protanopia, deuteranopia and tritanopia. It is a quick visual aid and not a clinical simulation, so use proper testing for accessibility decisions and never rely on colour alone to carry meaning. The Color Blind Test is a useful companion.

The colour name list

The list used here is a curated set of a little over 1,000 unique names. It is based on the open-source color-name-list project and the standard CSS colour names, trimmed so that the page loads quickly and runs in your browser. It includes familiar names such as Crimson, Coral, Cerulean and Chartreuse and some more unusual ones.

It is not a complete catalogue. There are about 16.7 million possible screen colours, so nearly every colour is matched to a neighbour and not to an exact name. Other lists contain other names, and the same colour can reasonably be called different things, which is why two websites sometimes disagree.

Accuracy and limits

The result is the nearest name in a list of about 1,100 entries, so it will often be an approximation. Colours look different on different screens, in different lighting and in print, and the CMYK values are a simple conversion and not a printer profile. The WCAG ratios follow the WCAG 2 formula and are guidance, not a compliance certificate. For exact brand, paint or print matching, use the manufacturer's official references.

Frequently asked questions

What is a free color name identifier online?

It is a tool that takes a colour value (a HEX, RGB or HSL code, a picked colour or a pixel from an image) and shows the closest matching colour name from its list of named colours. How do I find the name of a color from a HEX code?

Type or paste the HEX code into the Hex tab, for example #DC143C. The name of the closest match appears at once next to the swatch, with a distance number and four similar colours. You can also use the RGB, HSL, Colour picker or Image tabs.

How does colour name identification work?

The tool converts your colour into the CIELAB colour space, which is designed around human colour perception, and measures the CIEDE2000 distance to every name in its list. The name with the smallest distance is the closest match. This works better than comparing raw RGB numbers because equal RGB differences do not look equal to the eye.

How many colour names does the tool know?

It holds a little over 1,000 unique names, including the standard CSS colour names and a curated set of other common names. It is not a complete catalogue of every named colour, so many colours are matched to a near neighbour rather than an exact name.

What does the distance number mean?

It is the CIEDE2000 distance between your colour and the matched name. A value of 0 means an exact match and a lower number means a closer one. As a rough rule of thumb, differences of about 1 are hard to notice, and larger numbers mean a more visible difference. Treat it as a guide, not a measurement standard.

Why does another website give a different name for the same colour?

Colour names are conventions, and different lists contain different names. A colour between two names can be matched to either one depending on the list and the formula. The name is a helpful description, not a fixed fact about the colour.

No. The name shown is the nearest match in this tool's list. Paint makers, Pantone and RAL use their own catalogues and codes, so check the manufacturer's official reference when an exact commercial match matters.

What is the difference between HEX, RGB, HSL and CMYK?

HEX is a base-16 notation used in web design, RGB gives red, green and blue values from 0 to 255, HSL describes hue, saturation and lightness, and CMYK gives ink percentages for print. This tool shows all of them and LAB for the selected colour.

What are colour harmonies?

Harmonies are colour combinations based on positions on the colour wheel. Complementary colours are opposite each other, analogous colours sit next to each other, triadic colours are evenly spaced, and split-complementary uses the two colours beside the opposite one.

What is WCAG contrast and why does it matter?

WCAG contrast is a ratio between the lightness of two colours, usually text and background. WCAG 2 level AA asks for at least 4.5:1 for normal text and 3:1 for large text. This tool shows the ratio of your colour against white and black as a guide.
