Accessibility Tools

Free online tools for WCAG testing, color contrast, alt text, captions, text to speech, braille and accessible reading. Everything runs in your browser — no sign-up, no tracking.

Closed Caption GeneratorCreate SRT and VTT caption files for video, free in your browser. Text to Speech ReaderRead any text aloud with your device voices, speed control and word highlighting. Color Contrast CheckerCheck WCAG 2.2 and APCA contrast ratios for text and UI colors. Color Blind Test and SimulatorTake a 10-plate color vision screening and simulate color blindness on any image. Braille TranslatorTranslate text to Grade 1 or Grade 2 braille and back, with BRF download. Bionic Reading ConverterBold the start of each word for faster reading, with an RSVP speed reader. HTML Accessibility CheckerPaste HTML and test 48 WCAG rules with a score and fix guidance. Accessibility Statement GeneratorGenerate a website accessibility statement with US, EU, UK and Canada templates. WCAG 2.2 Checklist GeneratorTrack all 86 WCAG 2.2 success criteria and export an audit report. Alt Text CheckerScore image alt text, preview screen reader output and audit a whole page.
