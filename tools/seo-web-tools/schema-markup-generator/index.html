What this free schema markup generator does


Search engines read the words on your page, but they still have to guess what those words mean. Is that number a price, a phone number or a year? Is this person the author or someone mentioned in the text? Schema markup, also called structured data, removes the guesswork by labeling the facts in a standard vocabulary from Schema.org. The preferred format is JSON-LD, a small block of code in a script tag.
This free online schema markup generator builds that code from simple forms. It covers ten common types: FAQ, Article and blog post, Product, Local business, Organization, How-to, Event, Recipe, Breadcrumbs and Video. Each form marks the required fields, checks URLs and dates, and gives plain tips. The result updates as you type, and you can copy it or download it. Nothing is uploaded and there is no sign-up.


How to create schema markup in four steps


  1. Choose the type. Pick the schema type that matches the page, for example Product for a product page or Recipe for a recipe.
  2. Fill in the form. Complete the fields marked with an asterisk, then add the recommended ones. Press Load example if you want to see a finished version first.
  3. Read the checks. The panel under the form lists missing fields, invalid URLs and tips, and tells you whether the type can still produce a rich result.
  4. Copy and publish. Press Copy code, paste it into your page, then test the live URL with the Rich Results Test.

What changed for FAQ and How-to markup


For years FAQ schema was a popular trick for taking up more space in search results. In 2023 Google limited FAQ rich results to well-known government and health websites, and it stopped showing How-to rich results altogether. This tool still supports both, because the markup is valid, other engines and AI assistants may read it, and some sites still use it for clarity. But it labels them honestly as limited so you can decide whether the work is worth it.
If your goal is more visible results, spend your time on types that are still shown: Product, Recipe, Event, Video and Breadcrumb. If your goal is clarity for every system that reads your page, FAQ and How-to markup remain tidy, structured ways to state your content.


How JSON-LD is built


Every JSON-LD block starts with @context, which points to Schema.org, and @type, which names the thing you describe. The other properties are the facts about it. Properties can hold plain values, such as a name or a number, or other objects, such as an address inside a business. This tool builds those nested objects for you and removes empty fields, so the output stays small and clean.
Dates use ISO 8601 and times such as cooking durations use the form PT15M for fifteen minutes. Images and URLs must be full addresses. Prices are numbers with a separate three-letter currency code. The form takes care of these details, which are the most common sources of errors in hand-written markup.


Common structured data mistakes


  • Markup that does not match the page: prices, ratings or answers that visitors cannot see.
  • Fake or self-written reviews: ratings must come from real users.
  • Missing required properties: the page is then not eligible for the rich result.
  • Relative URLs: use full URLs with https.
  • Wrong date formats: use ISO 8601.
  • Marking up every page the same way: use the type that fits each page.
  • Blocking the page in robots.txt: Google cannot read markup on a page it cannot crawl.


Testing and monitoring your markup


After you publish the page, test the live URL with Google's Rich Results Test. It shows the types it detected, any errors that block eligibility and warnings about missing recommended fields. The Schema.org validator checks syntax for all types, including ones Google does not support for rich results. Over time, the Enhancements section of Search Console reports valid items, warnings and errors for the whole site and lets you ask Google to recheck after you fix problems.
Remember that eligibility does not mean you will always see a rich result. Google decides what to show based on the query, the quality of the page and policy rules.


Troubleshooting


  • The tool says a field is required: fill in the fields marked with an asterisk.
  • The Rich Results Test finds no items: make sure you pasted the whole script tag and that the page is public.
  • The stars do not show: ratings must be real and visible, and Google may not show them for every page.
  • A CMS rejects the script tag: choose JSON-LD only and paste it into a field meant for structured data.
  • The markup shows an error for dates: use the date fields so the format is correct.


Privacy and how it works


Your browser reads the form fields, builds a JSON object with the structure Schema.org expects and shows it as formatted text. Nothing is uploaded, stored or logged. Print / save summary creates a short report from the same data, and the rest of the page is not included in the print.


Frequently asked questions


What is a schema markup generator?
A schema markup generator is a tool that writes structured data for you. You fill in a form with details such as a product name, price and rating, and the tool creates JSON-LD code that you paste into your page so search engines can understand the content.
How do I create schema markup for free?
Choose a schema type, fill in the fields marked with an asterisk, and check the tips under the form. Then press Copy code and paste the result into the head or body of your page. The tool is free and needs no account.
What is JSON-LD and why is it recommended?
JSON-LD is a way to write structured data as a block of JSON inside a script tag. Google recommends it because it sits apart from your visible HTML, so it is easier to add, read and maintain than microdata.
Where do I paste the schema code?
Paste the script tag into the head of the page, or anywhere in the body. In WordPress you can use a header and footer plugin or your SEO plugin's custom schema field. In Shopify or other builders, add it to the page template or a custom code block.
Does schema markup improve rankings?
Google says structured data is not a direct ranking factor. It helps search engines understand your page and can make the result eligible for rich results, which may improve click-through rate. Results are never guaranteed.
Does FAQ schema still show rich results?
For most sites, no. Since 2023 Google shows FAQ rich results mainly for well-known government and health websites. The markup is still valid, and other search engines and AI tools may still read it.
Does HowTo schema still work?
Google stopped showing How-to rich results in 2023. You can still use the markup to describe steps, but do not expect a visual change in Google results.
Which schema types can get rich results?
Product, Recipe, Event, Video, Breadcrumb, Review snippets, Job posting and several others can be eligible. Google lists the current types and rules in its structured data gallery, which changes from time to time.
How do I test my schema markup?
Use Google's Rich Results Test to see whether your page is eligible for rich results, and the Schema.org validator to check general syntax. After the page is live, the Enhancements reports in Search Console show errors across your site.
Do I need to mark up every page?
No. Mark up pages where the content fits a type, such as products, articles, recipes, events and breadcrumbs. Reuse the same Organization markup on your home page rather than on every page.
Can I use more than one schema type on a page?
Yes. A product page can have Product and BreadcrumbList markup, and an article can have Article and Organization. Generate each one and add them as separate script blocks.
Does the markup have to match the page?
Yes. Google requires structured data to describe content that visitors can see on the page. Marking up hidden content, fake reviews or prices that do not match can lead to a manual action.
What are required and recommended properties?
Required properties must be present for a type to be eligible for a rich result. Recommended properties add detail and can improve the result. This tool marks required fields with an asterisk and gives tips for recommended ones.
How do I add review stars with schema?
Use the Product type and fill in the average rating and number of reviews. The ratings must come from real reviews that users can see on the page. Self-serving reviews of your own business are not eligible for stars in most cases.
What date format should I use?
Use the ISO 8601 format, such as 2026-03-14 or 2026-03-14T09:00. The date fields in the form create this format for you. Add a time zone offset to datetime values if the time matters to your audience.
Is my data uploaded anywhere?
No. The generator runs in your browser and builds the code on your device. Nothing you type is sent to Utiliby or any other server.
What can I print or save from the page?
Print / save summary gives a short report with the type, the checks and the code. Download file saves the markup as an HTML or JSON file. Copy code puts it on your clipboard.
