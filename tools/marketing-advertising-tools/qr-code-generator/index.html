Static versus dynamic QR codes

A static QR code stores its content in the pattern, so what you encode is what scanners get, and no server is involved. It cannot be edited after printing and it cannot report scan counts, but it never expires, works offline for content such as Wi-Fi and contacts and has no vendor to depend on. A dynamic code stores a short redirect link instead. You can change the destination later and see scan statistics, but the code only works while the service stays online and your plan is active, and the provider sees every scan.

For marketing campaigns, the best of both worlds is often a static code that points to a link you control, such as a page on your own site, which you can change and measure yourself. Add UTM parameters in the Website link type, or build them in the UTM Link Builder, and read the results in your analytics.

Designing a QR code that people scan

  • Contrast first. Dark code on a light background is the safest. Never invert.
  • Leave the quiet zone. Four modules of empty space on every side.
  • Keep the content short. Shorter links make simpler codes, which scan faster and print smaller.
  • Add a call to action. A frame that says what scanning does, such as See the menu, tells people why to scan.
  • Brand it carefully. Colours and a small logo are fine if you test, and level H error correction covers the logo.
  • Mind the surface. Matte paper scans better than glossy or curved surfaces.

Error correction, size and print tips

QR codes include Reed-Solomon error correction, so a damaged or partly covered code can still be read. The four levels recover about 7 percent (L), 15 percent (M), 25 percent (Q) and 30 percent (H) of the data. Higher levels add more codewords, so the code gets bigger and denser. Use M for clean prints, Q or H for outdoor, rough or logo-covered codes. The tool shows the version (the grid size, from 21 by 21 up to 177 by 177) and the module size in pixels at your chosen download size, and warns if modules fall below about 3 pixels.

For print, export SVG and place it at least 2 cm (0.8 in) wide for close scanning, and larger for posters, since distance needs size. A rule of thumb is a tenth of the scanning distance, so a code scanned from 2 metres should be about 20 cm wide. Leave space around it, avoid folds across the code and never stretch it unevenly.

Privacy and safe use

This generator works entirely in your browser. The text, Wi-Fi password, contact details and any logo you add are never uploaded, and no account is needed. Remember that a static code is not encrypted: anyone who scans a Wi-Fi code gets the password, so print it only where you are happy to share it. As a scanner, check the address your phone shows before you open a link, be wary of codes stuck over other codes, and never enter payment or login details on a page you reached without checking it.

Troubleshooting a QR code that will not scan

  • Low contrast. Darken the code or lighten the background.
  • Inverted colours. Use a dark code on a light background.
  • Too small. Print larger or shorten the content.
  • Too dense. Remove tracking parameters or use a shorter link.
  • Logo too big. Reduce it to 20 percent or less.
  • No quiet zone. Restore four modules of margin.
  • Gradients and dots. Make the lightest colour still dark enough, or use plain squares.

Accuracy, limits and responsible use

The generator follows the QR Code Model 2 standard (ISO/IEC 18004) in byte mode, with versions 1 to 40 and all four error correction levels, and the encoder has been checked against an independent decoder across every version and level. A code that is valid can still fail in practice if it is printed too small, on a poor surface or with low contrast, so always test the final print with more than one phone. Frequently asked questions

How do I create a QR code for free?

Choose what the code should do, such as open a website, then fill in the details. The code appears as you type. Download it as PNG or SVG. There is no sign-up and no watermark.

Do these QR codes expire?

No. They are static codes: the information is stored in the picture itself, so they work as long as the content, such as a website, still exists. There is no subscription that can run out.

What is the difference between static and dynamic QR codes?

A static code holds the data directly and cannot be changed after printing. A dynamic code holds a short link to a server that can be redirected and can count scans. Dynamic codes need an account and a service that stays online.

Can I track scans of this QR code?

A static code cannot count scans itself. For a link, you can add UTM campaign parameters, and your analytics tool will then show visits from the code.

How do I make a Wi-Fi QR code?

Choose Wi-Fi network, enter the network name and password, and pick the security type. Guests scan the code with their phone camera and can join without typing the password.

How do I make a contact (vCard) QR code?

Choose Contact card, fill in the name, phone, email and company, and download the code. Scanning it offers to save the contact to the phone.

Can I add a logo to the QR code?

Yes. Open Logo and frame, choose an image and set its size. The tool raises error correction to level H so the code still scans, and warns you if the logo covers too much.

What error correction level should I choose?

Level M is a good default. Use Q or H if the code may get dirty or scratched, or if you add a logo. Higher levels make the code denser.

What size should a QR code be for print?

At least 2 by 2 centimetres, or 0.8 inches, for close scanning, and larger for distance. A common rule is one tenth of the scanning distance. Always test before a large print run.

What file format is best, PNG or SVG?

Use SVG for print and anything that must scale, because it stays sharp at any size. Use PNG for web pages, documents and social media.

Why will my QR code not scan?

Typical causes are low contrast, an inverted (light on dark) code, a quiet zone that is too small, a code printed too small, too much data, or a logo that is too big.

Can I use colours in a QR code?

Yes, as long as the code is clearly darker than the background. Dark colours on a white or very light background work best. Avoid light codes on dark backgrounds.

How much data can a QR code hold?

Up to about 2,900 characters at the lowest error correction level, but short content makes simpler codes that scan faster.

Can I make a QR code for WhatsApp, SMS or email?

Yes. Choose WhatsApp, SMS text message or Email, add the details and the code opens a ready-to-send message when scanned.

Is it safe to scan QR codes?

Scan only codes from sources you trust and check the web address your phone shows before you open it. Be careful with codes stuck over other codes.

Can I print the QR code or save it as PDF?

Yes. Print or save creates a one-page sheet with the code, the settings and the encoded content. Only that sheet is printed, not the whole page.
