Types of PDF watermarks

Watermarks in PDF files come in several forms, and the difficulty of removal depends on the type:

Watermark typeHow it is embeddedRemoval difficulty
Annotation watermarkAdded as a PDF annotation object (stamp, free text, watermark annotation)Easy — can be removed via PDF API
Text watermark (page content)Drawn directly into the page content stream as textMedium — requires content stream editing or rasterisation
Image watermark (XObject)Placed as an image object on the pageMedium — can be removed if the XObject reference is identified

Tiled watermarkRepeated across the page at regular intervalsHarder — requires removing each tile
Background watermarkDrawn behind the main contentHarder — removal must not damage foreground content

This tool uses a rasterisation approach: it renders each page to a high-DPI canvas, removes the watermark from the image, and rebuilds the PDF. This works for every watermark type, but it converts the PDF to an image-based document. The text in the output is no longer selectable or searchable. If you need to preserve selectable text, use a dedicated PDF editor that can modify the content stream directly.

Removal methods explained

  • Inpaint (content-aware fill). The tool samples pixels from just outside the selected region and blends them inward to fill the watermark area. This works well when the watermark sits over a uniform background such as white paper or a light colour. It is the default and the most natural-looking option.
  • Fill with white. Replaces the entire selected region with solid white. Use this when the watermark sits over a plain white background and you want a guaranteed clean result. It will also erase any content inside the selected region.
  • Sample surrounding background. Analyses the pixels around the border of the selection, determines the dominant background colour, and fills the region with that colour. Useful when the page background is not pure white (for example, a light grey or cream paper texture).

Legal considerations: when can you remove a watermark?

Watermarks exist to assert authorship, indicate confidentiality or identify the source of a document. Removing a watermark is legally permissible only in specific circumstances:

  • You own the document. You created the PDF, or you own the copyright in the underlying content.
  • You have explicit permission. The copyright holder has given you written permission to modify the document.
  • The watermark is your own. You added the watermark yourself (for example, a "DRAFT" stamp) and now want to remove it.
  • The content is in the public domain. The work is not protected by copyright (very old works, or works explicitly released into the public domain).
  • Your use is covered by an exception. In some jurisdictions, limited exceptions exist for quotation, criticism, review or accessibility. These exceptions are narrow and vary by country.

In the United States, the Digital Millennium Copyright Act (DMCA) makes it illegal to "intentionally remove or alter any copyright management information" with reasonable grounds to know that the removal will facilitate copyright infringement. Watermarks that contain copyright notices, author names or source identifiers may fall under this provision. Similar laws exist in the EU, the UK and many other jurisdictions.

If you are unsure whether you have the right to remove a specific watermark, consult a qualified attorney. Do not use this tool to remove a watermark from a document you do not have permission to modify.

Tips for best results

  • Select a slightly larger region than the watermark. Include a few pixels of margin around the watermark to ensure it is fully covered.
  • Use auto-detect for coloured watermarks. If the watermark is a distinct colour (such as red or blue), enable auto-detect and adjust the tolerance. The tool will highlight all matching pixels in the page.
  • Match the method to the background. Use inpainting for watermarks over text or complex backgrounds. Use white fill for watermarks over plain white areas.
  • Increase the DPI for small watermarks. If the watermark is small or thin, render at 200 DPI so the tool has more pixels to work with.
  • Process page by page for irregular watermarks. If the watermark position varies across pages, use "Current page only" and select the region separately for each page.
  • Check the output before using it. The removal is an image-processing operation, not a semantic PDF edit. Inspect the result to ensure no important content was removed.
