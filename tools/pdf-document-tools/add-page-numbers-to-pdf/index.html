What this free page number tool does

Adding page numbers to a PDF sounds simple, yet most desktop editors lock it behind a paid plan, and many online services ask you to upload your file to a server. This free online tool adds page numbers to any PDF directly in your browser. You choose where the number sits, how it looks and which pages receive it, a live preview shows the result on a real page of your document, and one click downloads the finished file.

It covers the cases people actually need: start numbering after a cover page, begin at any number, use Roman numerals for front matter, write Page 1 of N or 1 / N, number only odd or even pages, mirror the position for book-style binding, and create Bates-style labels such as DOC-000123. Fonts, size, color and margin are adjustable, and landscape and rotated pages are handled correctly.

Cover pages, front matter and starting numbers

Many documents should not show a number on every page. A report with a cover page normally starts counting on the second page, so that the first content page reads 1. To do that, set First page to number to 2 and Start at number to 1. If your document has a table of contents and a preface that use Roman numerals, number those pages first with lowercase Roman style, download the file, and run the tool again on the same file with First page to number set to the first main page and Arabic numerals starting at 1. Because the second run only touches the pages in its range, the front matter keeps its Roman numbers.

The Chicago Manual of Style and most university thesis guides use this arrangement: lowercase Roman numerals for preliminary pages, Arabic numerals for the main text, and no visible number on the title page. Always check the rules of your institution or publisher, because some want numbers centered at the foot and others want them at the top right.

The Page X of N format helps the reader confirm that a printed document is complete. The total counts the numbered range, so if you number pages 2 to 40 starting at 1, the total reads 39 and the last page reads Page 39 of 39.

Bates-style numbering and document labels

Bates numbering gives every page in a set of documents a unique identifier, often a prefix followed by a fixed-width number such as ABC-000001. With the Custom text format you can build this yourself: type a pattern like ABC-{n}, set Start at number to your first number and set Zero-pad digits to 6. You can also add words around the number, for example Exhibit A, page {n}. This tool numbers one PDF at a time, so for a multi-file production, merge the files first, then number the combined PDF. Legal rules for numbering and confidentiality labels differ by court and by case, so confirm what is required before you rely on a simple label.

Landscape, rotated and mixed-size pages

PDF pages can be portrait, landscape or rotated by a viewing flag, and a single file can mix sizes. A naive tool puts the number at a fixed point and ends up sideways or off the page. This tool reads the size and rotation of every page, works out where the visual bottom or top is, and draws the text with the correct angle. The preview lets you check any page by number. Always open the downloaded file and look at a few landscape or rotated pages as well, since the preview is only approximate.

Printing and binding tips

  • Keep numbers at least 0.5 inch (36 points) from the edge, because many printers cannot print to the very edge.
  • For double-sided booklets use book style so that numbers sit on the outer edge.
  • Leave extra space on the bound side if you plan to staple or punch holes.
  • For dark scanned pages, choose a white or light color for the number or add a wider margin.
  • After printing a test copy, check that the number is readable and does not collide with an existing footer.

Common problems and how to avoid them

  • Numbers collide with an existing footer. Increase the margin or switch to the top of the page.
  • Numbers start at the wrong value. Check First page to number and Start at number, which are different settings.
  • Total is not what you expect. The total follows the numbered range, not the whole file.
  • Duplicate numbering. Running the tool twice on the same pages stacks two numbers. Re-run on the original file instead.
  • Special characters. Built-in fonts cannot draw every symbol, so use plain letters and numbers in custom text.

Page numbering conventions by document type

There is no single rule for page numbers, but each kind of document has habits worth following. Reports and business documents usually number from the first page after the cover, in the footer, centered or at the outer corner, with plain Arabic numerals. Theses and dissertations often use lowercase Roman numerals for the abstract, contents and acknowledgments, then restart at 1 for the main text, and many universities specify the exact position and margin in their formatting guide. Books and booklets use mirrored numbers on the outer edge so that they are easy to find when flipping pages. Contracts and legal packs favor Page X of N so that a missing page is obvious, and exhibits often carry their own prefix such as A-1, A-2.

When you are unsure, check the instructions given by the person who will receive the document. If there are none, bottom center with a plain number is almost always acceptable. Choose a font size between 9 and 12 points so that the number is readable but does not compete with the text, and keep at least half an inch from the edge so that printers do not cut it off.

Numbering a document made from several files

Page numbers should be added last. If you build a pack from several files, such as a cover letter, a report and appendices, first combine them with the Merge PDF tool, then add page numbers to the finished file so that the numbers run in one sequence. If you add numbers first and merge later, every file restarts at 1 and the result looks inconsistent. If you need separate numbering for the appendices, split the file with the Split PDF tool, number each part with its own start number and custom text such as A-{n}, then merge the parts again.

The same approach works for adding a total page count to a document that grows. Number the final version only, because the total in Page X of N is fixed at the moment you create the file. When you add or remove pages later, run the tool again on the original un-numbered file rather than on the numbered one, otherwise you will end up with two sets of numbers on each page.

For accessibility, remember that a number drawn onto a page is part of the page content and is read by screen readers like any other text. If a document is long and will be used on screen, consider also providing bookmarks in the source program so that readers can navigate without relying on printed page numbers.

Frequently asked questions

How do I add page numbers to a PDF for free?

Choose your PDF above, pick the position and format, check the live preview, then click Add numbers and download PDF. The tool runs in your browser, so there is no account, no watermark and no page limit beyond what your device can handle.

Is my PDF uploaded to a server?

No. The file is read and changed on your own device. The page downloads open-source PDF libraries from a public CDN the first time you use it, but your document is never sent anywhere.

Can I start numbering from a page other than the first?

Yes. Set First page to number to skip a cover or title page, and set Start at number to choose the first number shown. For example, start at page 2 with number 1 so the first numbered page reads 1.

Can I use Roman numerals for front matter?

Yes. Choose lowercase i, ii, iii or uppercase I, II, III under Number style. Number the front matter pages first, then run the tool again on the rest of the document with Arabic numbers.

How do I show Page 1 of N?

Pick the format Page 1 of N or 1 / N. The total is the last number in the numbered range, so it stays correct if you start at a different number or stop early.

Can I number only odd or even pages?

Yes. Use Which pages to select odd or even pages. This is helpful for double-sided printing where numbers go on one side only.

What is book style numbering?

Book style alternates the position so that odd pages carry the number on the right and even pages on the left, which keeps the number on the outer edge when pages are bound.

Can I add Bates numbers or document IDs?

Use Custom text with a pattern such as DOC-{n} and set Zero-pad digits to 6 to get DOC-000001. This is a simple Bates-style label. Check any court or discovery rules that apply to you.

Which fonts and colors can I use?

Helvetica, Times and Courier, which are built into every PDF viewer, in any size from 6 to 48 points and any color. Built-in fonts keep the file small and avoid missing-font problems.

Will this change the quality of my PDF?

No. The original pages, text and images stay as they are. The number is drawn on top of each page as live text.

Does it work on rotated or landscape pages?

Yes. The tool reads each page size and rotation and places the number in the visual footer or header, so landscape and rotated pages are numbered the right way up.

Why does it say my PDF is password protected?

The file is encrypted, so it cannot be changed. Remove the password in the program that created it, or print it to a new PDF, then try again.

Can I remove page numbers that are already in my PDF?

No. This tool only adds numbers. If you need to change existing numbers, edit the source document and export a new PDF.

Does it work on scanned PDFs?

Yes. A scanned PDF is a set of page images, and the number is added on top as text. The scanned content is not changed.

Is there a file size or page limit?

There is no fixed limit. Very large files depend on your device memory, so close other tabs for PDFs with hundreds of pages or many large images.

Will it work on my phone or tablet?

Yes, in a modern browser. Choose the file from your device storage, set the options and download the result.

What can I print or save?

Print / save summary prints only the settings and preview, and Copy summary copies the settings as text. The numbered PDF itself is the main download.
