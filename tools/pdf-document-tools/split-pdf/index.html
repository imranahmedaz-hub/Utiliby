What this free PDF splitter does

Sooner or later every PDF user needs only part of a document: one chapter from a long report, a single invoice from a monthly bundle, the signature page from a contract. Splitting a PDF is a paid feature in many desktop programs, and some online tools upload your file or cap the number of pages. This free online Split PDF tool works in your browser, with no upload, no sign-up and no watermark.

It offers three ways to work. Pick pages shows a thumbnail for every page so you can click what you want, then extract those pages, delete them, or save each as its own file. By ranges turns a list such as 1-3, 4-6, 7- into separate PDFs, or combines it into one. Every N pages cuts a long file into equal parts. Several files are delivered as a ZIP, and you can rotate selected pages along the way.

How to split a PDF

  1. Choose your PDF. Thumbnails of every page appear.
  2. Pick a method. Use Pick pages for a visual choice, By ranges to type page numbers, or Every N pages for equal parts.
  3. Check the plan. A table lists each file that will be created and the pages it will contain.
  4. Click Create and download. One file downloads as a PDF. Several files download as a ZIP.

Page range syntax

The range box accepts a simple list. Separate items with commas. A single number means one page, 3-6 means pages 3 to 6, 8- means page 8 to the end, and -3 means the first three pages. The words odd and even pick every other page. A range written backward, such as 6-3, outputs those pages in reverse order, which is a quick way to reverse a short section. Each item becomes its own PDF unless you tick Combine. If a number is outside the document, the tool shows a message that names the page and the allowed range.

Tips for splitting well

  • Use the thumbnails to find blank or separator pages quickly, then delete them in one go.
  • For bank statements or invoices that arrive as one file, check how many pages each document uses, then split with Every N pages.
  • Name your outputs: the tool uses the original file name plus the page numbers, so files sort in order.
  • When you only need to send one page, extract it instead of attaching a large file.
  • If pages appear sideways, rotate them in the Pick pages tab before you extract.

What is kept and what may be lost

The tool copies the page content directly, without re-drawing it, so text stays selectable, images keep their quality and the file stays sharp. What belongs to the document as a whole may not follow: bookmarks and the table of contents, named destinations, document-level JavaScript, and links that jump to pages that are no longer in the new file. Form fields on copied pages usually stay but may not be linked to the original form. Digital signatures cannot survive any change. If these features matter, check the result and rebuild bookmarks in an editor.

Troubleshooting

  • No thumbnails. Wait for the progress bar. PDFs with many pages load previews one after another.
  • Some pages look blank in the preview. The preview may not show unusual graphics, but the page content is still copied.
  • ZIP instead of PDF. More than one output file always downloads as a ZIP.
  • Password message. Unlock the PDF first.
  • Memory errors. Close other tabs or split a very large file in two steps.

What this tool does not do

It does not compress, redact, edit text, merge files or add page numbers. For those tasks use the Merge PDF, Compress PDF and Add Page Numbers tools on this site. It also does not recover pages from damaged files.

Extract, delete or split: which wording to remember

Extracting pages and deleting pages are two sides of the same operation. To keep 3 pages out of 100, extract those 3. To remove 3 unwanted pages from 100, delete those 3. Splitting divides a file into several files, either by ranges you choose or at regular intervals. The same tool does all three, so choose the one that needs the least clicking. A good habit is to look at the plan table under the thumbnails before you click the button: it lists every file that will be created and the pages it contains, so mistakes are easy to spot.

If you are reducing a file because it is too large to email, remember that removing pages is only one solution. The Compress PDF tool can shrink the pictures, and the Merge PDF tool can put the pieces back together after review. For a secure workflow, keep the original file until the recipient confirms that the split files are complete.

Large PDFs deserve a little patience. Thumbnails are drawn one after another, and the tool stays responsive while it works. You can already select pages for the first part of the document while later previews are still loading. If a particular page preview stays blank, the page may use an unusual feature, but the page is still copied correctly.

Privacy and how it works

The tool uses an open-source library to copy pages into new documents inside your browser, and a viewer library to draw the previews. Your PDF is not uploaded, stored or logged. The libraries are fetched from a public CDN the first time you use the tool, so you must be online at that moment. Closing the tab clears everything from memory.

Frequently asked questions

How do I split a PDF for free?

Choose your PDF, then use one of three methods: click page thumbnails to pick pages, type page ranges, or split after every N pages. Click Create and download to get a PDF or a ZIP of PDFs.

Is my PDF uploaded?

No. Your file is read and split on your own device. The PDF libraries are loaded from a public CDN the first time you use the tool, but your document is not sent to a server.

How do I extract certain pages from a PDF?

In Pick pages, click the pages you want, keep the action Extract them into one PDF, and download. The pages keep their order from the original.

How do I delete pages from a PDF?

In Pick pages, select the pages to remove, choose Delete them, keep the rest, and download. You can select with thumbnails or use the Odd, Even and Invert buttons.

How do I split a PDF into single pages?

Open the Every N pages tab and enter 1, or in Pick pages choose All and then Save each as its own PDF. You will get a ZIP with one PDF per page.

How do I split a PDF into equal parts?

Use Every N pages. For a 20-page file, N = 5 gives four PDFs of five pages. The last file holds any remaining pages.

What range format can I use?

Numbers and ranges separated by commas, such as 1-3,5,8-. An open range such as 4- runs to the last page, and -3 means pages 1 to 3. You can also type odd or even.

Can I rotate pages while splitting?

Yes. In Pick pages, select pages and click Rotate selected 90°. The preview turns, and the rotation is applied to the files you create from the Pick pages tab.

Can I combine several ranges into one file?

Yes. In By ranges, tick Combine all ranges into one PDF. The pages are added in the order you typed them, so you can also reorder pages, for example 5,1-4.

Will the quality change?

No. Pages are copied as they are, without re-rendering, so text stays selectable and images keep their quality.

Will bookmarks and links survive?

Not always. Page content is kept, but bookmarks, form fields and links between pages may not carry over to the new files.

Does splitting keep a digital signature?

No. Any change to a PDF invalidates an existing digital signature.

What if my PDF is password protected?

Remove the password first in the program that created it, or print to a new PDF, then try again.

Is there a page or file size limit?

There is no fixed limit. Thumbnails are shown for up to 400 pages, and very large files depend on your device memory.

Can I use it on my phone?

Yes, in a modern browser. Tap thumbnails to select pages, then download the result.

How do I merge PDFs back together?

Use the Merge PDF tool on this site to combine the pieces in any order.

What can I print or save?

Create and download saves the PDF or ZIP. Print / save plan prints the list of files that will be created with their pages, and Copy plan copies it as text.
