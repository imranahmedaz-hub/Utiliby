What this free PDF merger does

Combining several documents into one PDF is one of the most common office tasks: a cover letter with a CV, several invoices in one file, scanned pages from different sources, chapters of a report written by different people. Many tools charge for merging, limit the number of files, add a watermark, or require you to upload private documents to a server. This free online Merge PDF tool combines your files inside your browser, with no upload, no sign-up and no watermark.

Add as many PDFs as you like, and add images as well. Put them in the order you want with the arrow buttons, sort them by name, and choose which pages to take from each file with a simple range such as 1-3,7. A live list with thumbnails, page counts and sizes shows what you are about to create. When you click merge, one PDF is downloaded under the name you choose.

How to merge PDF files

  1. Add your files. Click the box or drop several files on it. You can add more at any time.
  2. Put them in order. Use the up and down arrows, Sort by name or Reverse order. The first file in the list becomes the first pages of the merged PDF.
  3. Choose pages (optional). In the Pages box of any PDF, type the pages to include, for example 1-3,7. Leave all to use every page.
  4. Name the file. Type the file name for the result. For images, pick Fit each image, A4 or US Letter.
  5. Click Merge and download PDF. A progress bar shows each file being added. Open the result and check it.

Choosing pages from each file

The Pages box accepts numbers and ranges separated by commas. 1-3 means pages 1 to 3, 5 means page 5, 8- means page 8 to the end, -2 means the first two pages, and odd or even select every other page. A range written backward, such as 5-1, adds the pages in reverse order. If a number is outside the document, the tool shows a message right under the box. You can also add the same file twice with different ranges, which is useful when you need to interleave sections from two documents.

Merging images and scans with PDFs

Any image you add becomes one page. Fit each image makes the page the same shape as the picture, which keeps scans and screenshots complete without borders. A4 and US Letter center the image on a standard page with a margin, in portrait or landscape to match the picture. JPG and PNG files are embedded directly without recompression, so quality is not reduced. Other formats such as WebP are converted to a high-quality JPEG first. If you only have images, the JPG to PDF tool on this site offers more layout options.

File size after merging

A merged PDF is roughly as large as the original files added together, because every page and image is copied as it is. If the same font or logo appears in several files, it is stored for each one. To make the result smaller, use the Compress PDF tool after merging. If you plan to email the file, check the limit of the mail service, which is often 20 to 25 megabytes. Splitting the result with the Split PDF tool is another option for very large combined documents.

Tips for clean merged documents

  • Name your source files with numbers such as 01-cover, 02-report, 03-appendix, then use Sort by name.
  • Check page sizes. A mix of A4 and Letter pages is fine, but the printed result may look uneven.
  • Merge first, then add page numbers with the Add Page Numbers tool so that numbers run across the whole document.
  • If a source file is a scan that is rotated, rotate it first with the Split PDF tool.
  • Keep your original files until you have checked the merged result.

Troubleshooting

  • A file shows an error. It may be password protected or damaged. Unlock it or re-save it from the original program.
  • A page looks blank in the thumbnail. Thumbnails are approximate. The page content is copied anyway, so check the merged file.
  • The page range is rejected. Check that the numbers are inside the page count shown for the file.
  • The browser slows down. Merge fewer or smaller files at a time.
  • Bookmarks are missing. Bookmarks do not carry over. Recreate them in a PDF editor if you need them.

What this tool does not do

It does not compress files, add bookmarks or a table of contents, edit text, fix damaged PDFs or keep digital signatures. It does not open password-protected files. For compression, splitting and numbering, use the Compress PDF, Split PDF and Add Page Numbers tools on this site.

Common merge workflows

Job and visa applications. Combine your cover letter, CV, certificates and references into one PDF in the order the form asks for. Invoices and receipts. Put the month's invoices into one file for the accountant, and sort them by name when the file names start with the date. Scans from different devices. Add the PDFs from the office scanner and the JPG photos from your phone and let the tool combine them, using A4 for the images. Reports and proposals. Merge chapters from several authors and then add page numbers to the result. Contracts with annexes. Merge the main agreement and the annexes in the agreed order, using page ranges to leave out unwanted cover pages.

If the combined file is too large for email, use the Compress PDF tool with a target size, or send a link to a shared folder.

Privacy and how it works

An open-source library reads your files in the browser, copies the chosen pages into a new document and saves it, all in your device memory. Nothing is uploaded, stored or logged. The library is loaded from a public CDN the first time you use the tool, so you must be online at that moment. Closing the tab clears every file from memory.

Frequently asked questions

How do I merge PDF files for free?

Click the box or drop several PDFs on it, arrange them in the order you want, and click Merge and download PDF. There is no account, watermark or file limit beyond what your device can handle.

Are my files uploaded to a server?

No. The files are read and combined on your own device. The PDF library is loaded from a public CDN the first time you use the tool, but your documents are never sent anywhere.

How do I change the order of the files?

Use the up and down arrows next to each file, Sort by name for numbered file names, or Reverse order. The list from top to bottom is the order of the merged PDF.

Can I merge only some pages of a PDF?

Yes. Each PDF has a Pages box. Type a range such as 1-3,7 to use only those pages, or leave it as all.

Can I add images such as JPG or PNG?

Yes. JPG, PNG and other common image files are added as pages. Choose whether each image fills its own page size or sits on A4 or US Letter.

Is there a limit on the number or size of files?

There is no fixed limit. Everything is held in your browser memory, so very large files or hundreds of pages can be slow on older devices. Merge in two steps if needed.

Will the quality of the pages change?

No. Pages are copied as they are, so text stays selectable and images keep their quality. The merged size is about the sum of the originals.

Can I merge password-protected PDFs?

Not directly. A protected file shows an error in the list. Remove the password in the program that created it, or print it to a new PDF, and add it again.

Will bookmarks, links and form fields survive?

Page content is kept, but bookmarks, form fields and links to other files may not carry over. Check the result if you rely on them.

Does merging keep digital signatures?

No. Combining files creates a new document, and existing digital signatures cannot be kept.

Why is the merged file larger than expected?

Fonts and images that appear in several source files are copied for each one. If the file is too big to send, use the Compress PDF tool afterwards.

Can I merge PDFs on my phone?

Yes, in a modern browser. Choose several files from your storage, reorder them and download.

Can I rotate or delete pages after merging?

Use the Split PDF tool on the merged file to delete or rotate pages, or pick the pages you want from each file before merging.

How do I merge PDFs in a particular order, like page 1 of one file and then another file?

Add the files, set a range such as 1 for the first file, and place the second file below it. To interleave pages more finely, add the same file twice with different ranges.

What name will the merged file have?

You can type any name in the Merged file name box. The default is merged.pdf.

Does it work offline?

After the first use the libraries may be cached by your browser, but the first load needs an internet connection. Your documents are never uploaded either way.

What can I print or save?

Merge and download PDF saves the combined file. Print / save file list prints the order of your files, pages used and sizes, and Copy file list copies the list as text.
