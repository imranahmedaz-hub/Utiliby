How upside-down text works

Upside-down text relies on Unicode — the universal character encoding standard that includes more than 140,000 characters. Among these are characters from the International Phonetic Alphabet, Latin Extended and Mathematical Operators blocks that happen to look like rotated versions of ordinary letters. The tool maps each character to its rotated equivalent and reverses the character order, so the flipped line reads correctly when the device is turned upside down.

Transformation modes explained

  • Upside-down. The classic flip. Each character is replaced with its rotated Unicode equivalent and the order is reversed. Reads correctly when viewed upside down.
  • Mirror. A horizontal reflection. Characters are replaced with their mirror-image equivalents where they exist, but the order is not reversed. Useful for creating a "looking-glass" effect.
  • Reverse. Simply reverses the order of characters without changing them. The text is backwards but each letter is upright.
  • Bubble. Converts letters to circled or enclosed Unicode characters (ⓐⓑⓒ), giving a rounded, playful look.
  • Small caps. Uses Unicode small-capital characters (ᴀʙᴄ) for a subtle typographic effect.
  • Fullwidth. Uses fullwidth Unicode characters (ａｂｃ) that occupy the same width as CJK characters. Useful for a "wide" aesthetic.

Limitations of upside-down text

  • Not all characters have a flipped equivalent. Numbers, punctuation and many symbols either map imprecisely or stay unchanged. The tool leaves them as-is.
  • Screen readers may not read flipped text correctly. Accessibility tools often cannot pronounce flipped Unicode, so use it for decoration rather than for essential information.
  • Some platforms filter unusual Unicode. A small number of sites strip or restrict non-standard characters. Instagram, TikTok, Discord and X are all fine.
  • Not searchable. Flipped text will not match a normal text search because the underlying characters are different.
