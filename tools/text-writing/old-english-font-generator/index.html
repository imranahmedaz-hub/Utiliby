Old English, Gothic, Blackletter and Fraktur: what is the difference?

These terms are often used interchangeably, but they are not exactly the same thing.

TermWhat it refers to
BlackletterThe broad family of ornate medieval scripts used in Europe from the 12th to the 17th century. Includes Textura, Rotunda, Schwabacher and Fraktur.
Old EnglishA colloquial name for Blackletter, popularised by 19th-century type foundries. It is not the same as the Old English language.
GothicAnother name for Blackletter. Also used, confusingly, for the unrelated Gothic architecture and the Gothic subculture.
FrakturA specific Blackletter style that became dominant in German printing. Unicode encodes Fraktur as Mathematical Fraktur (U+1D504–1D537) and Mathematical Bold Fraktur (U+1D56C–1D59F).

When an online Old English font generator produces "copy-and-paste Old English text", it is almost always using the Unicode Mathematical Fraktur block. That is the style this tool uses as its primary output.

Limitations of Unicode Old English text

  • Not all characters have a Fraktur equivalent. Numbers, punctuation and many symbols are not encoded in the Fraktur block. The tool leaves them as ordinary characters.
  • Not the same as a real Old English font. A downloaded font file (TTF, OTF, WOFF2) gives you the full character set, proper kerning and the ability to use it in a design app. Unicode text is a copy-paste hack that works in plain-text fields but not in print design.
  • Screen readers may mispronounce it. Fraktur characters are mathematical symbols, not letters, so assistive technology may not read them correctly.
  • Some platforms filter unusual Unicode. A few sites restrict Fraktur characters. Instagram, TikTok, Discord and X all accept them.
  • Not searchable. A search for "utiliby" will not match "𝔘𝔱𝔦𝔩𝔦𝔟𝔶".

Fonts vs Unicode: which do you need?

If your goal is to paste text into a bio or a username, use a Unicode generator. If your goal is to typeset a document, a poster, a tattoo stencil or a logo, you need an actual font file. Search a font library such as Google Fonts, Font Squirrel or DaFont for a Blackletter font, install it on your computer, and apply it in Word, InDesign, Illustrator or Figma. The Unicode approach is fast and free but limited to copy-paste contexts.
