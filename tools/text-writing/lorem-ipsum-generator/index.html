What lorem ipsum is and where it comes from


Lorem ipsum is the best-known placeholder text in design. Its words are adapted from a passage in De finibus bonorum et malorum, a work on ethics written by the Roman statesman Cicero in 45 BC. The adaptation scrambles and trims the Latin until it no longer has a meaning, which is the point. Readers see the shape of text, such as lines, paragraphs and rhythm, without being drawn into reading it.
Typesetters have used scrambled Latin like this for centuries to show how a typeface or layout will look. It became standard in desktop publishing and then on the web. The usual opening, Lorem ipsum dolor sit amet, consectetur adipiscing elit, is recognised by designers and clients everywhere, which is why the generator offers it as the default start.

Latin or themed English


Latin placeholder text has a practical advantage: it is obviously not real, so reviewers do not get distracted by the content. It also has a disadvantage. Latin words have a different average length and letter mix from English, so the text can look slightly unlike your real copy. Themed English fixes that. The business, tech, nature and legal themes build short, simple sentences from word lists, so the text has English word lengths and reads smoothly while still saying nothing of substance.
Whichever you choose, treat the result as filler. It is not accurate, it is not advice and it should never be published as real content.

Repeatable text with a seed


Random text is awkward when you need to reproduce a layout. A designer hands over a mockup, a developer builds it and the text is different every time, so spacing comparisons are confusing. The seed solves this. It feeds a small pseudo-random generator, so the same seed and the same settings always return the same placeholder text. Share the seed and the settings and a colleague gets identical content. Change the seed to see another variation, for instance to check that a layout holds up with longer and shorter words.


Judging typography in the preview


The preview tab sets the generated text in a column with the typeface, size, line height and width you choose. It is a quick way to test body text before you commit it to a stylesheet. Line length is the setting that most often goes wrong. Typographers recommend about 45 to 75 characters per line for body text. Shorter lines make reading choppy, and longer ones make it hard for the eye to find the start of the next line. A meter shows where your chosen width falls. Line height around 1.5 suits most body text, with a little less for large headings.


Tips for using placeholder text well


  • Use realistic lengths. Test with short, medium and long text, not only a neat three lines.
  • Test the extremes. Try an exact character count at your field limit and a very long unbroken string.
  • Keep placeholder text on staging. Replace it before launch.
  • Test with real content as soon as you can. Placeholder text hides problems such as long names and awkward line breaks.
  • Use the seed to share identical content across a team.
  • Check uppercase. Uppercase text is wider and shows overflow.


Common mistakes with placeholder text


  • Publishing it. Lorem ipsum on a live page gives users nothing to read and looks unfinished. Search engines treat it as thin content.
  • Designing only for tidy text. Real text has long words, short paragraphs and odd breaks.
  • Using the same three lines everywhere. Vary lengths to see how the layout copes.
  • Forgetting accessibility. Placeholder text cannot tell you whether headings are meaningful.
  • Judging copy by its filler. Placeholder text cannot test whether the message works.
