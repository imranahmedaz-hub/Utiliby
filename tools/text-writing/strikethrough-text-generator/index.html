How strikethrough text works

Unicode includes a category of characters called combining marks. These are characters that do not occupy their own space in a line of text; instead, they modify the character that precedes them. The combining mark used for strikethrough is U+0336, the Combining Long Stroke Overlay. When this character follows a letter, the browser renders it as a line drawn through that letter.

Strikethrough vs Markdown strikethrough

Some platforms — Discord, GitHub, Slack and Reddit — support Markdown strikethrough, where you wrap text in double tildes: ~~text~~. Markdown strikethrough is easier to type but only works on platforms that render it. Unicode strikethrough works everywhere, including platforms with no formatting support at all. This tool generates Unicode strikethrough; if you are writing for a Markdown platform, you can type the tildes directly.

Limitations of Unicode strikethrough

  • Not all apps render combining marks identically. Some fonts display combining marks with a small offset from the character. The effect still works, but the line may not sit exactly centred on every platform.
  • Screen readers may struggle. Combining marks can confuse assistive technology. Avoid using strikethrough for essential information.
  • Search and copy-paste can be affected. Searching for "price" will not match text that has strikethrough marks inserted. Copying the text into a search box may also fail if the combining marks are preserved.
  • Not the same as native strikethrough. The underlying characters are different. A word processor's spell check may flag it, and the text may not be counted correctly in a word count.
