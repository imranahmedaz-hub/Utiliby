What this free online Gantt chart maker does

A Gantt chart turns a list of tasks into a picture of time. Each task becomes a bar: the left edge is when it starts, the length is how long it takes and the position relative to other bars shows what overlaps and what must wait. Henry Gantt popularised the format in the early twentieth century, and it remains the standard way to present a project schedule because anyone can read it at a glance. This free online Gantt chart maker lets you build one without a spreadsheet, a licence or an account.

Add your tasks, give each a start date and a duration, link tasks that depend on each other, mark milestones and enter how far along each task is. The chart redraws on every keystroke, with weekends shaded, a today line, progress fill and arrows between linked tasks. When you are happy, download the chart as PNG or SVG, export the schedule as CSV or print a clean one-page version.

  1. Pick a starting point. Choose a template for a website launch, marketing campaign, product roadmap or event, or edit the sample tasks.

Understanding dependencies and the critical path

Most tasks cannot start until another finishes. Design comes before development and testing comes before launch. These links are called finish-to-start dependencies, and they are the type this tool supports. When you set a dependency, the later task begins the day after the earlier one ends, so lengthening an early task pushes everything after it. The chain of dependent tasks that determines the earliest possible finish date is called the critical path. In the chart, it is the longest staircase of linked bars from the first task to the last. A delay on that path delays the whole project, while tasks off the path have slack.

Use this to focus your attention. Shorten or start early the tasks on the critical path, and let off-path tasks run in parallel, such as writing content while designers work on mockups.

How to estimate task durations

Good estimates come from experience, not optimism. Break each task into pieces small enough to estimate in whole days, ask the people who will do the work, and compare with similar past tasks. Add buffer for review, feedback and the unexpected rather than hiding it in every task. Many teams add ten to twenty per cent contingency to the total or place a visible buffer task before important deadlines. If a task is longer than about ten working days, consider splitting it so progress is easier to track.

When to use a Gantt chart

Gantt charts suit projects with a clear beginning and end, defined tasks and dependencies: construction and renovation, software releases, marketing campaigns, events, research projects, product launches, school assignments and personal goals such as moving house or planning a wedding. They are less suited to continuous work with no end date, where a Kanban board or to-do list fits better. They also work as a communication tool: stakeholders who will not read a task list will usually understand a chart.

Tips for clear, useful charts

  • Keep names short. Long names are cut off in the left column.
  • Group by phase. Order tasks in the sequence they start.
  • Use milestones sparingly. Mark only the dates that matter.
  • Update weekly. Change progress and dates at a regular check-in.
  • Show the today line. It makes late tasks obvious.
  • Save a copy before big changes. Download the project file.

Tracking progress against the plan

A chart is most valuable after the project starts. Each week, update the percentage complete for every active task and check the red today line. A bar whose filled part ends well before the today line is behind schedule. Look at the critical chain of dependent tasks first, since delays there move the finish date. If you are behind, you can lengthen the task, add resources outside the tool, reduce scope or move the finish date, and then tell the people affected. Save a copy of the project file at each major change so you can compare the plan with what actually happened and improve future estimates.

Common Gantt chart mistakes

  • Too much detail. A chart with hundreds of rows is hard to read. Plan phases first.
  • No dependencies. Without links, one delay will not move later tasks.
  • Optimistic durations. Add review time and buffers.
  • Ignoring weekends and holidays. Use working days and add days for holidays.
  • Never updating it. An old chart misleads. Refresh progress regularly.

Frequently asked questions

What is a Gantt chart?

A bar chart that shows a project schedule. Tasks are listed down the side and time runs across the top, so each bar shows when a task starts, how long it takes and how it overlaps with others.

How do I make a Gantt chart with this free online tool?

Choose a template or start from scratch. Name each task, set a start date and duration, and the chart builds as you type. Download it as PNG or SVG or print it.

Do I need Excel or an account?

No. It runs in your browser with no sign-up, no download and no spreadsheet formulas.

What is a task dependency?

A link that makes one task start only after another ends. Enter the number of the earlier task in the After # box, and the later task moves automatically if the earlier one changes.

What is a milestone?

A key point in the project with no duration, such as a launch or sign-off. It is drawn as a diamond on a single date.

Can I count only working days?

Yes. Tick Count working days only to skip Saturdays and Sundays when calculating end dates. Public holidays are not skipped, so add extra days where you need them.

How do I show progress?

Enter the percentage done for each task. The bar fills in proportion, and the average progress of all tasks is shown above the chart.

What does the red dashed line mean?

It marks today's date, so you can see which tasks should be underway. You can hide it with the Show today line option.

Can I download the chart as an image?

Yes. Download PNG for slides and documents or SVG for sharp scalable graphics. The image always has a clean white background.

Can I print the Gantt chart?

Yes. Print / save chart prints only the chart and a table of tasks and dates, not the rest of the page. Choose landscape in the print dialog for wide charts.

Can I export the schedule to a spreadsheet?

Yes. Download CSV creates a table with task, start, end, days, progress and dependency that opens in Excel or Google Sheets.

Is my project saved?

Yes, automatically in this browser on this device. Use Save project to keep a JSON copy and Open project to restore it elsewhere.

How many tasks can I add?

Up to 60 tasks, which suits most small and medium projects. Larger programmes are better split into phases.

Can I reorder tasks?

Yes. Use the up and down buttons. Dependency numbers are updated for you so links stay correct.

What is the difference between a Gantt chart and a Kanban board?

A Gantt chart plans work over time and shows dependencies. A Kanban board shows the status of work now. Many teams use both.

Does it work on a phone?

Yes. The task editor adapts to small screens and the chart scrolls sideways.

Is it free and private?
